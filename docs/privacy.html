Privacy policy

Agent Zero for Android, maintained by TerminallyLazy, connects your Android device to an Agent Zero server that you choose. It does not include a hosted AI account or a developer-operated chat service.

Your server and your data

Messages, files, microphone audio, sign-in information, and other actions in the workspace go to your selected server and any services that server uses. The server operator’s policies and configuration govern that processing, retention, and access. Connect only to a server you trust. This app does not send that content to a separate TerminallyLazy analytics or AI service.

What stays on the device

The app stores server names and HTTPS addresses, plus the WebView cookies, cache, and browser storage needed for your sessions. App data is excluded from Android backup and device transfer. Where supported by Android System WebView, each saved server has its own browser profile.

Optional permissions

  • Camera: used only when you choose native QR scanning. Images are decoded on the device and are not saved or uploaded by the scanner. Choosing a saved QR image uses Android’s file picker.
  • Microphone: requested when your selected server asks for voice input. Audio may be sent to that server and its configured voice providers. The app stops its captured microphone tracks when backgrounded.
  • Files: you choose specific upload files and download destinations through Android’s system picker. The app does not request broad access to your files.
  • Local network: on Android versions requiring it, permission allows a selected HTTPS server on your network to be reached.

No advertising or app analytics

The native app has no advertising SDK, analytics SDK, crash-reporting upload service, or push notification service. The server-provided WebUI can make its own requests according to the server’s configuration; this policy does not promise that third-party servers or their model providers collect no data.

Download website

This website uses no analytics, cookies, or third-party QR generation. A prefilled server address appears only in the URL fragment and is processed in your browser; it is not sent to the website host by this page. GitHub hosts the website and release downloads and processes normal web-request information under its own privacy statement.

Removing data

Use Servers → Forget to clear a saved server and its local browser session when supported by your WebView. Android Settings → Apps → Agent Zero → Storage → Clear storage removes all local app data. Files you saved outside the app remain where you saved them. Chats, uploaded files, and accounts on the server must be removed through that server or its operator.

Contact

For privacy questions or app support, open an issue in the project. Do not include passwords, tokens, private server URLs, or chat content in a public issue.
